# Contributing

Contributions to `bounded-canonical-prefix` are welcome within its bounded scope.

1. Run offline tests and the independent C11 consumer check before submitting changes:
   ```sh
   /bin/sh scripts/test-offline.sh
   /bin/sh scripts/demo-offline.sh --assert
   ```
2. Maintain zero third-party Nim package dependencies.
3. General contact: [Lofrano Tecnologia](https://lofranotecnologia.com.br).
