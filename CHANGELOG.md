# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - Unreleased

### Added
- Larmore–Hirschberg package-merge length-limited Huffman codebook builder (`package_merge.nim`).
- `BCP1` binary format encoder and strict decoder (`bcp1_codec.nim`).
- Independent brute-force optimality oracle for small alphabets (`oracle.nim`).
- Independent native C11 `BCP1` verifier (`tools/bcp1_c_consumer.c`).
